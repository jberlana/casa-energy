# Configuration examples

Examples document schema, not a working installation. `collector-config.example.json` intentionally
has empty authorization fields and a null home ID. Copy it to a private runtime directory, then fill
it locally. Do not replace placeholders in this folder with real identifiers or paths.

Any future example must use empty or clearly synthetic values and be added deliberately to
`PUBLIC_FILES.txt`. Put actual configuration under `.local/` or outside the repository.
